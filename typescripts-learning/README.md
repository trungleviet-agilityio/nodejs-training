# TypeScript Learning Path

This directory contains comprehensive TypeScript learning materials, examples, and exercises.

## 📁 Directory Structure

```
typescripts-learning/
├── src/
│   ├── basics/          # Basic TypeScript concepts
│   ├── interfaces/      # Interface definitions and usage
│   ├── classes/         # Class-based programming
│   ├── generics/        # Generic types and functions

│   └── advanced/        # Advanced TypeScript features
├── tests/              # Test files for examples

```

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- TypeScript installed globally: `npm install -g typescript`

### Setup
```bash
# Navigate to the TypeScript learning directory
cd typescripts-learning

# Install dependencies
npm install

# Compile TypeScript files
npm run build

# Run in development mode
npm run dev

# Run tests
npm test
```

## 📝 Exercises and Examples

Each topic includes:
- **Theory**: Explanation of concepts
- **Examples**: Practical code examples
- **Exercises**: Hands-on practice problems
- **Tests**: Unit tests for validation

### Running Examples
```bash
# Run a specific example
npm run dev src/basics/01-types.ts

# Run all examples in a directory
npm run dev src/basics/

# Run tests for a specific topic
npm test src/basics/
```

## 🛠️ Development Workflow

3. **Complete exercises** in the exercise files
4. **Run tests** to validate your solutions
5. **Create your own examples** in the examples directory
